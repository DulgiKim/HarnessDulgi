마이그레이션 파일 번호는 리드 세션이 홀수, 작업 세션이 짝수를 쓴다.

**왜:** 두 세션이 병렬로 마이그레이션을 만들면서 같은 번호를 선점해 두 번 충돌했다. 번호가 겹치면 적용 순서가 꼬이고, 뒤늦게 발견하면 파일명과 참조를 전부 고쳐야 한다.

**적용:** 새 마이그레이션 파일을 만들기 전에 자기 레인의 패리티를 확인한다. 저장소 바깥에서 선점될 수 있는 전역 식별자는 패리티로 해결되지 않으므로, 적용 직전에 현재 상태를 조회해 충돌을 확인한다.
