여러 사람이 동시에 수정하는 파일(씬, 설정, 에셋)은 전체를 커밋하지 않는다. 변경 헝크 단위로 골라서 스테이징한다.

**왜:** 이런 파일에는 다른 작업자의 로컬 변경이 상시 섞여 있다. 파일 단위로 커밋하면 남의 작업을 그대로 덮어쓰고, 되돌리려면 수작업으로 분리해야 한다.

**적용:** 변경 내역을 컨텍스트 없이 뽑아 내가 만든 헝크만 골라 스테이징한다. 커밋 전에 스테이징된 내용을 다시 확인한다. 씬을 복제할 때는 파일 복사가 아니라 에디터의 복제 기능을 쓴다. 파일 복사는 내부 참조 ID가 그대로 남는다.
